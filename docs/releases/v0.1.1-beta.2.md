## Upgrade notice

This beta uses **Peerline transfer protocol v4**. Upgrade both sending and
receiving installations. TCP/BLE completion replies are now authenticated with
the receiver's session key; Peerline does not silently fall back to v3's
unauthenticated completion ACK.

Incompatible versions are rejected before receiving files or creating resume
state. The error identifies both protocol numbers and asks you to upgrade the
older installation. The receiver stays available, and route probing preserves
the version error instead of replacing it with a later connection failure.

## Changes

- Add an offline BLE GATT file-data channel with `recv --ble` and
  `send --ble <name> <path...> --code <code>`. It uses Peerline authentication
  and encryption, requires a powered Bluetooth adapter, and has no IP fallback.
- Add explicit `recv --copy-code`. The copy expires after 30 seconds when it
  still belongs to Peerline; later clipboard contents are preserved. Copying
  is never automatic.
- Add opt-in, experimental macOS AirDrop receiving with `recv --airdrop`,
  explicit approval for each batch, bounded uploads and guarded archive
  extraction. AirDrop uses native AWDL/HTTPS, separately from Peerline's
  password-authenticated protocol.
- Update dependencies and native Bluetooth/WebRTC integrations. Fix Bluetooth
  cleanup, repeated macOS initialization, Rust 1.100 compatibility and ARM64
  musl linking.
- Preserve historical releases and downloads so previously published npm
  versions remain installable. Validate startup of all seven platform binaries
  before publication.

## Qualification limits

Two-device BLE transfers with IP networking disabled and interoperability with
physical Apple AirDrop senders have not yet been qualified. AirDrop remains
experimental. Clipboard expiry is best effort and cannot erase clipboard
history or copies made manually from terminal output.

## Install

```sh
npm install -g peerline@beta
peerline --version
```

The stable npm `latest` tag remains on 0.1.0. Platform binaries and SHA-256
checksums are attached to this release.
