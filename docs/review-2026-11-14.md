# Implementation review — 2026-11-14

Scope: dependency/API migrations, vendored WebRTC, the shared byte-stream
transport, offline BLE, controlled clipboard copying, AirDrop receive and docs.

## Findings fixed

- Clipboard acknowledgement loss could kill or prematurely exit the expiry
  worker after it had copied the code. The parent no longer kills that worker
  on an acknowledgement timeout; broken stdout does not bypass expiry. Its
  independent process group also survives the receiver's terminal Ctrl-C.
- BLE receive now closes advertising on setup/clipboard failures as well as
  ordinary shutdown. The peripheral dependency no longer powers Linux adapters
  on automatically, spins after a macOS manager closes, or rejects a later
  macOS manager instance through a process-wide singleton.
- TCP/BLE completion success was a plaintext ACK. It now requires a reply
  authenticated with the receiver's session key. Protocol version 4 explicitly
  rejects older peers; both ends must upgrade.
- The published OPAQUE prerelease retained crypto-bigint 0.5.5, covered by
  RUSTSEC-2026-0387. Pin the upstream RustCrypto migration at
  `070eac916fa58c71029a13021c127861f58d11d1`, remove the old SHA-2 alias and use
  current APIs. No advisory is suppressed.
- AirDrop confirmation discards pre-offer keystrokes, ignores key-release
  events and reports expired offers accurately. Archive directory separators
  are normalized narrowly; root entries also count toward the entry limit.
- Updated the vendored WebRTC smoke tests for the migrated rand API and fixed
  a Windows-only test import warning.

## Evidence

- Workspace: 171 tests passed; the one hardware-gated test is ignored in the
  default suite and passed separately on this Mac (two consecutive peripheral
  create/close cycles).
- Vendored WebRTC: 9 unit, native smoke and documentation tests passed from an
  isolated copy of the vendored crate.
- Node launcher/release tooling: 37 passed, 1 intentionally skipped.
- Formatting, strict workspace Clippy and JavaScript syntax checks passed.
- Linux x86_64 musl binary linked statically; Windows x86_64 GNU workspace and
  all targets passed cross-target checking. These are not Windows/Linux runtime
  Bluetooth or clipboard tests.
- Full Worker WASM/bundling build passed. Both lockfiles have zero vulnerability
  findings in cargo-audit. The main lockfile retains unmaintained notices for
  atomic-polyfill (target-specific), paste and pin-utils.
- macOS private-pasteboard tests verify owned-generation cleanup and preservation
  of subsequent copies, including identical text, without touching the user's
  general clipboard. A broken parent-acknowledgement pipe is covered separately.
- Local AirDrop protocol tests cover approval, expiry, peer binding, single use,
  malformed archives, staging cleanup, existing-file preservation and actual
  HTTPS chunked upload. Native libarchive fixtures cover files, folders and
  empty directories, gzip integrity and padding.
- A real CLI PTY probe over this Mac's AWDL address passed discovery, rejection
  of pretyped `y`, intentional terminal approval, file-content equality and
  Ctrl-C shutdown. The local client enabled Darwin's SO_RECV_ANYIF, as required
  for AWDL sockets. Advertising/idle-exit cleanup was also checked.

## Remaining qualification

No review or finite test suite proves absence of every bug. Physical two-device
BLE transfer with IP networking disabled, and iPhone/iPad/Mac AirDrop sender
compatibility across OS releases, remain unqualified. AirDrop stays explicitly
experimental and macOS-only. Clipboard cleanup is best effort and cannot erase
third-party history or manual terminal copies; macOS has no atomic public
compare-and-clear pasteboard operation.
